# 安装与使用

## 测试安装包

需要 Apple Silicon Mac 和 macOS 15+。解压完整安装包，双击 `Where is my token.app`，选择“安装并启动”。运行环境已内置，不需要另外安装 Python、Xcode 或其他依赖。当前测试包尚未做 Developer ID 签名与 Apple 公证。

这是本机监测组件，不能通过导入 Codex 插件 ZIP 安装。它不注册任何 Codex 钩子，也不向对话发消息。

## 数据位置

安装在 `~/Library/Application Support/Where is my token/`，用户启动项为 `~/Library/LaunchAgents/local.whereismytoken.launcher.plist`。设置在 `preferences.json`，增量统计在 `data/`；本机 Codex 路径在 `runtime-config.json`，不写进已签名的应用包。升级保留这些资料；不会修改其他产品的启动项。

## 启动、退出与恢复

- 打开 Codex 普通窗口：启动悬浮条与本机采集服务。
- 关闭最后一个普通窗口或退出 Codex：数秒内结束监测，空闲的轻量启动监听保留。最小化和切换应用不算关闭。
- 点击小条的 ×：收起为 W·T 圆按钮，点击圆按钮恢复；菜单栏还有备用入口。
- 设置中的“退出监测”：本次窗口会话内保持退出，下次打开新的 Codex 窗口会话后恢复。也可以手动打开安装目录内的应用。

关窗策略通过隔离原生窗口测试，实际 Codex 各版本行为仍需兼容性验证。

## 监测设置

刷新频率可选 5／10／30 秒；可开关警示。固定模式支持搜索并选择对话，以及展示其所属项目。

“跟随最近发送”在开启后等待下一条已提交的用户消息，包括新任务首条消息。后台回复、工具活动和旧记录重放不会触发。它不是界面选中状态跟随，不读取未发送草稿；重启后需要等待新消息。小条顶部始终显示实际监测对象。

项目只汇总本机目录中可读取的范围，每次有界推进；读取完成前不生成声称完整的项目小票。不同对话的上下文不相加。

## 打印设置

打印默认关闭。开启后可选择当前监测对话或其所属项目、消耗最高的前 N 轮或全部轮次、58／80 mm 纸宽，以及是否显示 API 金额。只有一种小票模板。

蓝牙页显示已配对经典蓝牙设备及连接状态。选择设备后主动点击连接；不自动配对或断开其他设备。选择有线模式时使用已安装的系统打印机。蓝牙设备没有对应系统打印队列时，不会回退到其他打印机。

点击预览后，通过 macOS 系统打印框手动打印。厂商专用 BLE 协议、喵喵机等设备以及真实出纸尚未验证；支持蓝牙不代表任何蓝牙打印机都能使用。

## 语言

跟随 macOS 首选语言，支持简体中文、繁体中文、英文、日文、法文、德文和韩文，其他语言回退英文。更改系统语言后重启监测生效。ChatGPT、Codex、模型名、设备名和对话标题保留原文。

## 停用与移除

双击安装包中的 `Disable.command`。

停用只退出监测并移除自己的启动项，设置、统计和安装文件保留。如需完全删除，可在停用后自行删除上述安装目录；这会同时删除该目录内的监测数据，不影响 Codex 聊天。
