# 隐私与数据

## 读取什么

监测只在本机计算，读取本机 Codex 保存的对话目录、选定范围的用量记录和必要的活动标记。跟随模式解析新提交用户消息的事件标记以切换目标，不保存其文本。不读取账户密码、访问令牌、未发送草稿或界面选中状态。

原始记录按字节和条数预算读取，文本只在内存中短暂解析。统计库存储必要数字、模型、时间、标识、来源散列及归属关系，不复制提示词、回答、完整工具输入输出或聊天记录。日志活动只采样明确文件的大小、修改时间和文件身份，不扫描全盘。

启动监听只检查 Codex 进程及公开窗口元数据中的所属进程、层级、大小和透明度，不读取标题、界面内容或截图。

## 保存在哪里

完整应用使用自己封装的 Python，不安装或修改系统 Python。自动启动版本保存在 `~/Library/Application Support/Where is my token/`：`preferences.json` 为界面设置，`data/` 为增量统计。关闭窗口后统计保留，便于下次续读。停用不会删除数据。

统计按实际用量增长，状态缓存有界；不保存无限运行日志。启动监听的标准输出和错误丢弃，本机 HTTP 服务不写访问日志。历史统计的删除由用户决定。

## 网络与权限

不上传统计、不自动联网更新价格、不额外调用模型、不向 Codex 对话注入消息，也不发送 macOS 通知。点击 GitHub 或问题反馈按钮会打开对应网页；反馈由你填写和提交，不自动附带聊天、日志或统计。

服务只监听 `127.0.0.1` 的随机端口，每次启动生成随机路径，并验证 Host 和 Origin。该地址是本机会话访问凭据，不应分享。界面与小票资源不从远程加载；接口不提供对话消息或删除入口。

打印默认关闭。开启蓝牙打印相关功能时使用 macOS 蓝牙权限，读取已配对经典蓝牙设备和连接状态；选择设备后需主动点击连接。不自动配对或断开其他设备。实际打印必须经过系统打印框，数据交给你选择的系统打印队列；网络打印机可能通过网络接收打印内容。

## 发布与移除

公开仓库只包含产品介绍、展示图、使用许可及反馈资料，不公开应用源码。安装包不包含开发者的聊天、账户资料、统计数据库、订阅设置和运行日志。示例图与小票使用虚构数据。

`Disable.command` 仅停用自己的启动项并退出监测，保留设置、统计和安装文件。Codex 自己保存的聊天不受本产品控制。
