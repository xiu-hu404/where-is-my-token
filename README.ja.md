**macOS 向け Codex トークン使用量・コスト管理ツール。**

作業はまだ終わっていないのに、トークンだけが増えていく。どこで使われているのでしょうか。Where is my token は、会話ごとのトークン使用量、キャッシュヒット率、コンテキスト使用率を小さなバーに表示します。キャッシュの再利用が少ない状態やログの増加に気づき、Codex の使い方を見直すきっかけをつくります。

![Codex の会話上部にトークン使用量を表示する利用イメージ](docs/images/codex-workflow-en.jpg)

Codex の作業画面は利用イメージです。モニターバーは実際の画面から撮影し、会話と数値にはサンプルを使用しています。紹介画像は英語版で統一しています。

## できること

- **使用量を把握する。** ログを探さずに、会話ごと・プロジェクトごとの累計トークンを確認できます。
- **見直すタイミングを知る。** 最近のキャッシュヒット率が低い状態や、ログの増加が続くと、バー内で知らせます。
- **コストを振り返る。** 確認できる API 料金をもとに費用を換算し、モデル別の使用量や消費の多いターンをレシートで確認できます。
- **判断は自分で。** 集計はローカルで行います。追加のモデル呼び出し、会話へのメッセージ送信、モデルの自動変更、ファイルの自動削除は行いません。

会話を固定するほか、追従を有効にした後で新しく送信されたユーザーメッセージに合わせて対象を切り替えたり、そのプロジェクト全体を集計したりできます。Codex のウィンドウに連動して起動・終了し、macOS の言語設定に従います。日本語、英語、簡体字中国語、繁体字中国語、フランス語、ドイツ語、韓国語に対応。ChatGPT、Codex、モデル名は原表記を使います。

## レシートと通知

![トークン数、所要時間、API 換算額、ターン別使用量をまとめたレシート](docs/images/receipt-showcase-en.jpg)

レシートは必要なときだけ作成します。会話単位・プロジェクト単位、消費量上位 N ターン・全ターン、58／80 mm 幅、API 金額の表示・非表示を選べます。印刷は初期状態では無効です。有効にすると、ペアリング済みのクラシック Bluetooth 機器やシステムのプリンターを選び、macOS の印刷画面で確定できます。

![キャッシュヒット率の低下を示すオレンジ色の点と説明](docs/images/advisory-showcase-en.jpg)

オレンジ色の点は、最近のキャッシュヒット率が低いことを示します。右側は、点にポインタを重ねたときに表示される説明です。見直しの手がかりであり、トークンの無駄を断定するものではありません。

## インストールと停止

現在は **0.1.0-beta.4**。**Apple Silicon 搭載 Mac、macOS 15 以降**が必要です。実行環境は同梱されているため、Python や Xcode のインストールは不要です。

テスト用パッケージを入手したら、次の手順で使えます。

1. `Where-is-my-token-0.1.0-beta.4-macOS-arm64.zip` を展開します。
2. `Where is my token.app` を開き、インストールして起動する項目を選びます。
3. 停止するには `Disable.command` を実行します。設定と集計データは残ります。

Codex の通常ウィンドウをすべて閉じると、モニターと収集サービスが終了し、ウィンドウを開くと再開します。最小化では停止しません。軽量の起動監視プロセスはバックグラウンドに残ります。バーの × を押すと W·T ボタンに折りたたまれ、クリックすると元に戻ります。

現時点では Developer ID 署名と Apple の公証を受けていません。Codex と併用するローカルツールであり、ZIP を Codex のプラグインフォルダに取り込む方式ではありません。Codex Hooks の有効化も不要です。

## プライバシーと現在の制約

- 読み取れるローカルの Codex 記録から必要な統計を保存します。会話全体は複製せず、統計データもアップロードしません。保存先は `~/Library/Application Support/Where is my token/` です。
- 追従対象は新しく送信されたメッセージです。画面で選択中の会話や未送信の下書きには追従しません。
- キャッシュヒット率は回答の正確さを示しません。コンテキスト使用率から内容の必要性は判断できず、使用率が高いだけでは警告しません。
- 集計対象はこの Mac で収集できた記録だけです。不明な使用量や料金は「—」と表示し、プランから残りトークン数を推定しません。
- API 換算額は実際の請求額ではありません。サブスクリプション料金の手動入力と月ごとの按分は管理コマンドから行い、デスクトップのレシートは主に API 換算額を表示します。
- ログの通知はファイルサイズと更新時刻に基づき、物理的なディスク書き込み量は計測しません。テスト実行タイミングの助言は、まだモニターバーに接続されていません。
- Bluetooth 印刷には対応する macOS 印刷キューが必要です。メーカー独自の通信方式と実際の印刷は未検証です。起動・終了の連動は隔離したウィンドウで検証済みですが、Codex 各バージョンでの互換性確認が必要です。
