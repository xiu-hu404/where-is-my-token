**macOS에서 Codex 토큰 사용량과 예상 비용을 확인하세요.**

작업은 아직 끝나지 않았는데 토큰은 계속 늘어납니다. 어디에 쓰이고 있을까요? Where is my token은 대화별 토큰 사용량, 캐시 적중률, 컨텍스트 사용률을 작은 막대에 보여 줍니다. 캐시 재사용이 줄거나 로그가 계속 커지는 상황을 살펴보고, Codex 사용 방식을 조정할 단서를 찾을 수 있습니다.

![Codex 대화 상단에서 토큰 사용량을 확인하는 사용 예시](docs/images/codex-workflow-en.jpg)

Codex 작업 화면은 사용 상황을 재현한 이미지입니다. 모니터 막대는 실제 인터페이스를 캡처했으며 대화와 수치는 예시입니다. 소개 이미지는 영어로 통일했습니다.

## 어떤 도움이 되나요?

- **사용량을 한눈에 확인합니다.** 로그를 직접 뒤지지 않아도 대화별·프로젝트별 누적 토큰을 볼 수 있습니다.
- **점검할 시점을 알려 줍니다.** 최근 캐시 적중률이 계속 낮거나 로그가 지속해서 커지면 막대 안에 알림을 표시합니다.
- **비용을 돌아봅니다.** 확인된 API 요금으로 예상 금액을 계산하고, 영수증에서 모델별 사용량과 토큰을 많이 쓴 턴을 확인합니다.
- **결정은 사용자가 합니다.** 로컬에서 계산하며, 모델을 추가로 호출하거나 대화에 메시지를 보내지 않습니다. 모델 변경이나 파일 삭제도 자동으로 수행하지 않습니다.

특정 대화를 고정하거나, 추적을 켠 뒤 새로 전송한 사용자 메시지에 따라 대상을 바꾸거나, 해당 프로젝트의 합계를 볼 수 있습니다. Codex 창에 맞춰 시작하고 종료하며 macOS 언어 설정을 따릅니다. 한국어, 영어, 중국어 간체·번체, 일본어, 프랑스어, 독일어를 지원합니다. ChatGPT, Codex, 모델 이름은 원래 표기를 유지합니다.

## 영수증과 알림

![토큰, 소요 시간, API 예상 비용, 턴별 사용량을 정리한 영수증](docs/images/receipt-showcase-en.jpg)

영수증은 필요할 때만 만듭니다. 대화 또는 프로젝트, 사용량 상위 N개 턴 또는 전체 턴, 58／80 mm 용지 폭, API 금액 표시 여부를 선택할 수 있습니다. 인쇄는 기본적으로 꺼져 있습니다. 인쇄를 켜면 이미 페어링된 클래식 Bluetooth 기기나 시스템 프린터를 선택하고 macOS 인쇄 창에서 확인할 수 있습니다.

![낮은 캐시 적중률을 알리는 주황색 상태 표시와 설명](docs/images/advisory-showcase-en.jpg)

주황색 점은 최근 캐시 적중률이 낮다는 뜻입니다. 오른쪽에는 점 위에 포인터를 올렸을 때 나오는 설명을 보여 줍니다. 점검을 위한 단서일 뿐, 토큰이 낭비되었다는 증거는 아닙니다.

## 설치와 비활성화

현재 버전은 **0.1.0-beta.4**입니다. **Apple Silicon Mac과 macOS 15 이상**이 필요합니다. 실행 환경이 포함되어 있어 Python이나 Xcode를 따로 설치할 필요가 없습니다. 

테스트 패키지를 받았다면 다음과 같이 설치합니다.

1. `Where-is-my-token-0.1.0-beta.4-macOS-arm64.zip`의 압축을 풉니다.
2. `Where is my token.app`을 열고 설치 후 시작하는 항목을 선택합니다.
3. 비활성화하려면 `Disable.command`를 실행합니다. 설정과 통계는 유지됩니다.

마지막 Codex 일반 창을 닫으면 모니터와 수집 서비스가 종료되고, 창을 다시 열면 시작합니다. 최소화하면 계속 작동합니다. 창이 열리는지 감지하는 작은 프로세스는 백그라운드에 남습니다. 막대의 ×를 누르면 W·T 버튼으로 접히며, 버튼을 누르면 다시 펼쳐집니다.

현재 베타에는 Developer ID 서명과 Apple 공증이 적용되지 않았습니다. Codex와 함께 사용하는 로컬 도구이며, Codex 플러그인 폴더에 ZIP을 가져오는 방식이 아닙니다. Codex Hooks를 켤 필요도 없습니다.

## 개인정보와 현재 한계

- 이 Mac에서 읽을 수 있는 Codex 기록을 바탕으로 필요한 통계만 저장합니다. 대화 전체를 복사하거나 통계를 업로드하지 않습니다. 저장 위치는 `~/Library/Application Support/Where is my token/`입니다.
- 새로 전송한 메시지를 따라갑니다. 화면에서 선택한 대화나 아직 보내지 않은 초안을 추적하지 않습니다.
- 캐시 적중률은 답변의 정확도를 뜻하지 않습니다. 컨텍스트 사용률만으로 내용이 필요한지 판단할 수 없으며, 사용률이 높다는 이유만으로 경고하지 않습니다.
- 이 Mac에서 수집한 기록만 집계합니다. 알 수 없는 사용량이나 가격은 ‘—’로 표시하며 구독 요금제를 바탕으로 남은 토큰을 추정하지 않습니다.
- API 금액은 환산한 예상 비용이며 실제 결제 금액이 아닙니다. 구독료 직접 입력과 월별 배분은 현재 관리 명령으로 처리하며, 데스크톱 영수증은 주로 API 금액을 표시합니다.
- 로그 알림은 파일 크기와 수정 시각을 기준으로 하며, 실제 디스크 쓰기 양을 측정하지 않습니다. 테스트 실행 시점에 관한 조언은 아직 모니터 막대에 연결되지 않았습니다.
- Bluetooth 인쇄에는 호환되는 macOS 인쇄 대기열이 필요합니다. 제조사 전용 통신 방식과 실제 출력은 아직 검증하지 않았습니다. 창에 따른 시작·종료는 분리된 테스트 창에서 확인했으며 Codex 버전별 호환성 검증이 남아 있습니다.

소스 코드를 공개하지 않는 무료 소프트웨어이며 **비상업적 용도로만 사용할 수 있습니다**. 비상업적 목적의 무료 복제, 수정, 재패키징, 재배포는 허용하지만 재판매, 유료 묶음 판매, 소프트웨어 기능의 유료 제공은 금지합니다. 자세한 내용은 [라이선스](LICENSE)를 확인하세요.
