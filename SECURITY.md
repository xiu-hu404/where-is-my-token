# Security / 安全问题

Report security vulnerabilities through [GitHub private vulnerability reporting](https://github.com/xiu-hu404/where-is-my-token/security/advisories/new). Ordinary bugs and suggestions belong in [Issues](https://github.com/xiu-hu404/where-is-my-token/issues).

Include the app version, macOS version, and anonymous steps to reproduce the issue. Do not submit passwords, API keys, full conversations, or personal usage databases. There is no guaranteed response time. This beta has not undergone an independent security audit.

Supported release: **0.1.0-beta.4**. Older builds are not maintained.

安全漏洞请通过 [GitHub 私密报告](https://github.com/xiu-hu404/where-is-my-token/security/advisories/new)提交，普通问题与建议请使用 [Issues](https://github.com/xiu-hu404/where-is-my-token/issues)。

请提供应用版本、macOS 版本及匿名重现步骤，不要提交密码、API 密钥、完整聊天或个人统计数据库。目前不承诺固定响应时间；此测试版尚未经过独立安全审计。

当前维护版本：**0.1.0-beta.4**。旧构建不再维护。
